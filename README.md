# Python Automation Examples

A collection of Python automation and scripting projects demonstrating web scraping, real-time monitoring, speech processing, and bot development.

## Projects

### [`/speech-to-text`](./speech-to-text)
Real-time speech-to-text transcription using Python. Demonstrates audio stream capture and live transcription pipelines.

### [`/electronics-bot`](./electronics-bot)
Automated availability and pricing checker for electronics (RTX GPUs) across Best Buy and NVIDIA. Polls product pages and alerts on stock/price changes. Demonstrates web scraping, scheduling, and notification logic.

### [`/twitch-lurker`](./twitch-lurker)
Twitch.tv chat lurker bot built in Python. Connects to Twitch IRC, monitors chat streams, and automates interactions. Demonstrates IRC protocol handling and bot architecture.

## Tech Stack
- Python 3
- Jupyter Notebooks
- `requests`, `BeautifulSoup` (web scraping)
- `speech_recognition` (audio processing)
- `socket` / IRC (Twitch integration)
